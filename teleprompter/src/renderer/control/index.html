Controle remoto (pedal/clicker Bluetooth)

Funciona como um teclado — basta parear o dispositivo no sistema. Estes atalhos ficam ativos globalmente enquanto a tela de exibição estiver aberta:

  • Espaço — play / pause
  • ↑ / Page Up — aumentar velocidade
  • ↓ / Page Down — diminuir velocidade
  • ← — voltar um trecho
  • → — avançar um trecho
  • Shift+R — reiniciar do topo
  • Shift+M — espelhar
